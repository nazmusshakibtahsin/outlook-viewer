# Outlook Inbox Viewer — PHP ভার্সন

## সহজ ইনস্টল
1. সব ফাইল হোস্টিংয়ে আপলোড করুন (PHP 7.4+)।
2. cPanel-এ একটা MySQL ডেটাবেস আর ইউজার বানান।
3. ব্রাউজারে `yoursite.com/install/` খুলুন — ডেটাবেসের তথ্য আর অ্যাডমিন নাম/পাসওয়ার্ড দিয়ে "Install now" চাপুন।
4. শেষ হলে সার্ভার থেকে `install` ফোল্ডার মুছে দিন।
5. `yoursite.com/admin/` থেকে মেইলবক্স যোগ করুন।

মেইল দেখতে: `yoursite.com/?email=x@outlook.com` অথবা `yoursite.com/mail/x@outlook.com`
আবার ইনস্টল করতে চাইলে `installed.lock` ফাইল মুছে দিন।
